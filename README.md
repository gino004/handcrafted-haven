# Handcrafted Haven

## Project Description

Handcrafted Haven is a web application that allows artisans to showcase and sell their handmade products. Customers can browse products, search by category, view seller profiles, and leave reviews.

## Technologies

- Next.js
- React
- Node.js
- JavaScript
- CSS / Tailwind CSS
- Database (to be implemented)
- Vercel

## Project Goal

The goal of this project is to build a modern, responsive marketplace for handcrafted products while applying full-stack web development concepts learned in WDD 430.
